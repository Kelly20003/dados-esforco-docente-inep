# Análise da Educação Básica na Paraíba (Censo Escolar / INEP)

## 📌 Descrição do Projeto

Este repositório contém o projeto de análise de dados desenvolvido para a disciplina de **Projeto Integrador** na **Universidade Estadual da Paraíba (UEPB)**, elaborado pela equipe composta por **Kelly, Pietra e Manuela**.

O objetivo principal do projeto é analisar o panorama da Educação Básica no estado da Paraíba a partir dos microdados do Censo Escolar disponibilizados pelo INEP. A pesquisa investiga a distribuição das escolas entre as diferentes redes de ensino (Estadual, Municipal, Privada e Federal), o nível de acesso a recursos tecnológicos (internet, banda larga e laboratórios de informática) e a concentração do volume de matrículas pelos municípios paraibanos.
